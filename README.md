# Entrelaço Terapia de Casal

Site institucional estático para **Entrelaço Terapia de Casal**.

## Estrutura
- `index.html` — conteúdo e estrutura do site
- `styles.css` — identidade visual e responsividade
- `script.js` — menu mobile e animações
- `assets/` — fotos e demais arquivos

## Fotos
Adicione as fotos profissionais com estes nomes:
- foto principal
- foto da seção "Sobre mim"
- imagem complementar

Se os arquivos ainda não existirem, o site exibe um placeholder.

## Rodar localmente
Basta abrir `index.html` no navegador. Para desenvolvimento, também pode usar a extensão Live Server do VS Code.

## GitHub
Crie um repositório e envie todos os arquivos desta pasta.

```bash
git init
git add .
git commit -m "Site inicial Entrelaço Terapia de Casal"
git branch -M main
git remote add origin URL_DO_SEU_REPOSITORIO
git push -u origin main
```

## Observação
Antes da publicação definitiva, revise os textos profissionais, dados de contato e regras aplicáveis à divulgação profissional.
